## Data Boundaries & Architectural Decisions

1. **RESTRICTED vs FULL Permissions:** `RESTRICTED` is per-booking, not whole-account. Couples with unconfirmed or pre-deposit bookings can switch bookings, view profile and catalog, and see clear guidance cards with Web handoff buttons rather than experiencing app-wide lockouts.
2. **Web Handoff Environment Variable:** Hand-offs strictly utilize `readPublicEnv().EXPO_PUBLIC_WEB_PORTAL_URL`. Auth tokens are never appended to URLs in query strings.
3. **Headcount & Seating Separation:** Planned headcount is independent of named guest counts. Group seating operates without requiring individual named guests. Check-in mode `NONE` is represented as "Chưa ghi nhận", never zero.
4. **Server-Calculated Billing:** Integers in VND only. Client never computes or passes payment amounts for balance settlement; it provides only `expectedBillingRevision`.
5. **Vietnamese Typography:** Strictly Be Vietnam Pro sans-serif for all Vietnamese copy (`HyBody`, `HyBody500`, `HyBody600`, `HyBody700`). No CSS uppercase or tracking modifications on Vietnamese text. Serif font (`HyDisplay`) is restricted solely to the static Latin monogram "HY".
